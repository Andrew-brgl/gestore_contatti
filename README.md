# Gestore Contatti

Web application sviluppata con Laravel e PostgreSQL per la gestione
di contatti istituzionali e gestione di inviti ad eventi

## Tecnologie

- Laravel
- PHP
- PostgreSQL
- Eloquent ORM
- Laravel Migrations
